# ALWedding2026

Welcome to our wedding website project for our special day in 2026.

This repository hosts the website for our wedding celebration and contains the content, styling, and structure used to share our event details with family and friends. The site is built with Jekyll and published through GitHub Pages.

## About this project

This website is designed to provide a warm and welcoming place for guests to find key information about our wedding, including:

- the date and venue
- ceremony and reception timings
- RSVP information
- additional details for the day
- helpful links and updates for attendees

## Website details

Our wedding celebration will take place on:

- Date: 1 November 2026
- Location: Bickley Mill Inn, Stoneycombe, Newton Abbot TQ12 5LN

The site is intended to be a simple, elegant, and easy-to-navigate experience for those joining us on our special day.

## Local development

To run the site locally, use the following steps:

```bash
cd docs
bundle install
bundle exec jekyll serve
```

Then open the local preview in your browser, usually at:

```text
http://localhost:4000
```

## Deployment

This project is published using GitHub Pages from the `docs` folder.
